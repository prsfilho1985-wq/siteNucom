Retificar dados retenção

Em caso de execução errada do código da consignação na RT é possível fazer a correção do código do favorecido na funcionalidade Retificar Dados Retenções, cadastrando o Novo código e o novo CNPJ. Ou fazer a quebra do valor dessa retenção, transformando em 2 retenções.

Atenção: Solicitar a UG um documento comprobatório dos dados corretos para efetuar a alteração.

Exceção: Quando é RT de IRRF ou RT INSS no código 01, não é possível fazer essa alteração nessas funcionalidades. Apenas por demanda para o IRRF.
