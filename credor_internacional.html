Credor Internacional

Para cadastrar um Credor Internacional é necessário solicitar à UG um documento com as informações para o Manter Credor Inscrição Genérica: Nome, endereço, o NIF. O RN envia os pagamentos de credores internacionais para uma conta do BB e nesta conta do BB é enviado o pagamento para o destinatário final. Ou seja, a OB descentralizada não vai ser enviada direto para o destino internacional final.

OBS: Se não tiver NIF pode marcar como Beneficiário dispensado do NIF.

Para cadastrar utiliza-se o Manter Credor Inscrição Genérica – Número 26. E é possível consultar um cadastro similar como modelo no Listar Credor – Inscrição Genérica – Número 26.
